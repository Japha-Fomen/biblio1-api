biblio1-api

API REST de gestion de bibliothèque — auteurs, livres, membres et emprunts.

Java 21 · Spring Boot 4 · Spring Data JPA · Docker · Render

Points d'entrée

GET/actuator/healthÉtat du service
GET/api/livres?page=0&size=10Liste paginée des livres
GET/api/livres/{id}Détail d'un livre
GET/api/livres/isbn/{isbn}Recherche par ISBN
POST/api/livresCréation d'un livre
GET/api/auteurListe paginée des auteurs
GET/api/membreListe paginée des membres
POST/api/empruntsEnregistrement d'un emprunt
POST/api/emprunts/{id}/retourRetour d'un livre
Service hébergé sur un plan gratuit : après une période d'inactivité, le premier appel peut prendre jusqu'à une minute, le temps que l'instance redémarre. La base de données est en mémoire et repart vide à chaque redémarrage.

Le projet

Architecture en couches, DTO par opération, validation à l'entrée, exceptions métier dédiées et profils de configuration par environnement. Le code, la documentation complète et une collection Postman de 45 requêtes automatisées sont publics : github.com/Japha-Fomen/biblio1-api.
